## 页面性能约束

修改后台页面、共享脚本或列表接口时，必须检查以下边界；不能仅靠隐藏加载提示改善体感。

- **首屏主链路**：列表、筛选、详情基础字段不得等待图表库、地图底图、统计或外部资料回填。统计独立请求，先显示已返回的数字，再绘图；ECharts 统一通过 `AdminAssets.loadCharts()` 按需加载，共用一个可失败重试的 Promise，不重新引入阻塞式 vendor script。外部回填在首轮列表和统计展示完成后启动。
- **公共资源缓存**：CSS、JS、图标、地图 JSON 等嵌入资源使用内容版本 URL；HTML 引用由 `assets.go` 统一注入，动态 URL 使用 `AdminAssets.url()`。版本匹配才允许 immutable 长缓存，未带版本或旧版本保留 ETag 重验证；修改资源必须自然改变版本，禁止手写长期不变版本号。不要新增外网 CDN 依赖。
- **标签栏图标**：`assets.go` 为后台页面（含登录、找回密码页）统一注入带内容版本的 `static/favicon.png`，复用 Android 客户端正式版 48×48 应用图标；更新品牌图标时同步该资源。
- **标签栏标题**：后台各页面统一使用“时光轨迹 - 控制台”，包含发布管理、登录和找回密码页；具体功能名称保留在页面标题及导航中。
- **导航品牌**：`shell.js` 左上角统一显示“时光轨迹 / 控制台”，使用同一应用图标替代字母T，资源通过 `AdminAssets.url()` 加版本，并标记 `data-no-preview`；沿用桌面双行、窄屏隐藏副标题的布局。
- **缓存隔离**：公共资源缓存不包含用户上传图片、业务数据、会话或权限。受保护 HTML/API 继续 no-store，每次受保护请求实时验证账号状态和权限；不得为提速缓存鉴权结果。压缩含身份的 HTML 不得进入共享静态 gzip 缓存。
- **局部更新成本**：MutationObserver 只处理新增或受影响子树，同批去重；禁止每次图表、列表或提示变化都扫描整个 document。权限状态刷新仍做全量应用，新增表单、字段和业务脚本重新启用 disabled 时必须及时恢复只读锁；观察器自身写 DOM 要避免递归触发。
- **列表数据与资源**：优先批量查询、按唯一用户/资源去重，禁止在逐行循环里重复读取同一作者。图片缓存未命中等确需等待的 I/O 使用有上限并发（当前 `list_assets.go` 为 4），保留请求取消与单次超时；响应顺序稳定，不创建每行一个无限制 goroutine，不提前返回尚未落盘的本地资源地址。
- **异步与验收**：快速筛选/刷新忽略旧响应，失败可重试，局部统计失败不阻断列表操作。自查首次进入、再次切页、慢图表/图片和只读账号路径；遵守根文件的验证约定，默认仅构建与静态自查，功能由用户手动验证。未实测不得宣称首屏提速比例或耗时。

### 详情与编辑入口

- `AdminUI.runOnce(key, action)` 在执行入口前登记同类任务，重复点击复用整个异步工作流；动态编辑器的任务应覆盖加载、弹窗关闭及保存收尾，不能只对创建弹窗那一刻去重，也不要让多个调用方拿同一份表单返回值重复写入。
- `AdminUI.form({load(signal), ...})` 先显示一个可关闭的加载弹窗，`load` 返回表单配置后在原弹窗内填充；失败可原地重试，关闭时取消加载，入场动画期间快速关闭也会完整收尾。`onReady({root, form, signal})` 用于非阻塞的辅助选项加载，不得覆盖用户已经选择的值。
- 共享轨迹编辑器自身保留单实例任务；轨迹列表复用本页已加载的城市选项，其他入口在详情显示后独立加载城市选项，失败保留当前城市并允许重试。地图、图片、候选等继续异步加载，不阻断基础表单。
- 用户、反馈、路线组、景点等固定弹窗复用既有节点，重复加载合并或取消旧请求，关闭/切换时忽略旧响应。发布详情、更新日志等动态弹窗在创建前登记实例，直到隐藏并释放后才允许再次打开；从景点/反馈详情进入轨迹编辑的往返流程也需去重，避免关闭后又重复弹回。

## 卡片布局与边距约束

- **内容留白默认存在**：卡片里的标题、说明、错误提示、筛选和按钮不得贴边。共享内容内边距默认桌面 18px、窄屏 14px，复用 style.css 的统一规则；不要只给当前截图某一行补 margin，留下其他状态或同类页面继续贴边。
- **检查增强后的结构**：`static/ui.js` 的 `enhanceCard` 有两种结构：独立 `.panel.card > .card-body`，以及没有直接 H2 时的同节点 `.panel.card.card-body`（包括标题放在复合工具栏内的情况）。两种都必须有内边距，不能让 `.panel.card { padding: 0 }` 覆盖同节点内容。改共享 Card/CSS 时同时检查这两条路径，不能仅凭 HTML 里有 card-body 就认为留白生效。
- **贴边必须显式且局部**：只有纯表格或其他明确设计为满宽的区域可用 `p-0` 等标记；账号列表纯表格和景点纯表格是现有例子。不得把包含标题、说明和筛选的整个业务卡片设为零内边距。表格贴边时仍保留单元格留白，文字/表单恢复正常内容边距。
- **工具栏和宽表格不突破留白**：普通筛选工具栏使用专用 flex/grid 类，不直接借用 Bootstrap `.row`；`.row` 的负边距必须和成对的列 gutter 一起使用，不能让标题、筛选和表格边界错位。反馈页复用 `admin-toolbar feedback-toolbar`：标签/控件分成固定行，三个控件高度 40px，按钮独立分组且与控件底部对齐，分页说明放在工具栏外；中等宽度按钮整组换行，窄屏字段独占一行。不能仅加 align-items 而忽略标签高度、控件高度与换行结构。宽表格包在独立 `.table-responsive` 内，包含弹窗内的配置表，不能让整个卡片或弹窗横向溢出。
- **提交前布局自查**：修改后台页面或共享增强逻辑时，对照桌面和窄屏规则，检查卡片四边、标题/说明/表格对齐、工具栏换行，以及加载/空态/报错/展开详情后的留白；长文本或宽表格只能在各自内容区换行或滚动。沿用根文件的人工验收约定，未实看页面不得声称视觉验收通过。
- **展开详情不重分配列宽**：含可展开详情或长请求路径的业务表格，先明确列宽比例并用 colgroup + table-layout:fixed 固定，不能依赖自动内容测宽。最近操作记录的时间/操作人/操作内容/操作对象/结果固定为 18%/12%/34%/22%/14%，长路径、ID 和结果标签在单元格内换行，展开只改变行高；桌面最小表宽 900px，由外围表格容器局部滚动。767px 以下继续使用移动卡片布局，隐藏 colgroup 并解除最小表宽，详情/结果说明保持在内容列，不把桌面列宽强加给卡片。

## 共享统计组件与选用

新增或调整统计区域先盘点现有组件，有合适的就复用；共性变化修改共享组件并检查调用方，不按页面再复制一套卡片、周期按钮或图表样式。纯业务数据、权限、请求取消和筛选语义由页面负责，展示组件不发请求、不缓存用户数据，也不把不同统计口径合并。

| 重复展示 | 统一入口 | 使用方式与边界 |
| --- | --- | --- |
| 指标数字、说明、告警色、可点击指标 | `static/admin_stats.js` 的 `AdminStats.metric`、`data-admin-metric` | 指标根节点保留原生article/button/a及权限属性，标签和值使用textContent；不把用户ID转Number |
| 紧凑指标组 | `static/admin_stats.css` 的 `.admin-metrics` | 一层外边框、内部细分隔，按可见项自动适配列数，600px以下两列；不再叠加独立大卡片和阴影 |
| 统计标题、周期、刷新 | `.admin-stats-heading`、`.admin-period-tabs` | 原生button、role=group和aria-pressed；仅统一展示/初始语义，页面继续负责周期与刷新事件，不增加重复请求 |
| 统计容器、图表容器与网格 | `.admin-stats-panel`、`.admin-chart-panel`、`.admin-chart-grid` | 12px/14px内边距、10px间距、8px圆角；ui.js识别统计面板后不再另包一层card-header/card-body |
| 次要统计展开 | `.admin-stat-disclosure`、`AdminStats.onExpand` | 原生details/summary；展开后再测量和绘图，隐藏尺寸为0时不初始化ECharts；数据请求仍由页面掌握 |
| 环形、图例、细柱与配色 | `AdminChartStyle.ring/bars/legend/colors` | 复用用户管理基准；legend可传同一色板，保证色块与图形对应，默认调用兼容 |
| 通用表格、按钮、弹窗、图片预览 | 既有`ui.js` / Tabler | 继续复用AdminUI与既有增强；指标按钮和周期按钮显式跳过通用按钮染色 |
| 地区选择、共享轨迹编辑 | 既有`region_picker.js`、`track_editor.js` | 沿用现有组件；本轮不将地图供应商、权限或业务表单强抽成通用统计逻辑 |

统计页面加载顺序：Tabler CSS → style.css及页面CSS → admin_stats.css；Tabler JS → shell.js → admin_stats.js → ui.js → 页面脚本。使用图表工厂时在页面脚本前加载admin_chart_style.js，ECharts仍由AdminAssets.loadCharts异步加载。静态统计节点在页面脚本执行前同步生成，保留原数值ID、说明ID、按钮ID及data-admin-read；后续业务代码照常按ID局部更新。

声明式示例：

```html
<div class="admin-metrics">
  <article data-admin-metric data-label="活跃用户"
    data-value-id="activeUsers" data-note-id="activeUsersDelta"
    data-note="正在加载" data-admin-read="users"></article>
</div>
```

动态指标用`AdminStats.metric({label, value, note, valueId, noteId, tone})`返回节点；支持warning/danger两个语义告警。动态插入声明节点后显式调用`AdminStats.enhance(root)`，可重复调用，不另加全页MutationObserver。组件使用25px数字、12px标签、11px辅助说明及等宽数字；移动端数字22px，长说明换行，不用省略号隐藏统计口径。

已接入工作台、投稿审核、反馈、同行、景点、发布、实时通信、AI使用的数值区（50项声明式指标及AI动态指标），以及用户、轨迹、地图模式等共11页的顶部统计容器/标题/周期或图表样式。没有统计区的页面不为了统一而新增空统计。用户地图原有三列与响应式区域定义保留。

工作台顶部只展示活跃、新增用户、新增轨迹、上传用户及新增投稿，重复的待审核、待反馈和活跃同行集中到对应区块；不改变统计口径。次要审核结果和反馈来源折叠，业务标题保留、重复解释性段落移除；卡片头40px、主要趋势225px、分布190px，减少逐层留白。转化阶段改用共享细柱数量/占比，仍以同周期注册用户为分母，不改变Cohort。

## 图表统一规范

- 用户约定（2026-11-04）：管理后台同类统计图表以用户管理页为视觉基准，统一配色、字体、图例、中心数值、柱宽、浅色底轨、卡片边框与留白，禁止按页面另写相互偏离的图表配置。
- `static/admin_chart_style.js` 提供 `AdminChartStyle.ring/bars/legend`，用户管理与轨迹管理共同消费；HTML 在页面脚本前加载该文件。颜色使用用户画像原有 Tabler 色板；环形图采用 57%–82% 半径、白色分隔、中心总数与说明，侧边复用 `admin-user-legend`。横向柱状图采用 12px 细柱、圆角、浅灰底轨、隐藏数值轴及轴线；按场景显示数量或数量/占比，不为了视觉一致伪造统计口径。
- 轨迹统计区保持紧凑：标题 14px、图表内容区 200px、环形图 160px；桌面两卡片并排，窄屏上下排列，环形图与侧边图例保留两列以控制高度。十名用户完整显示，长昵称省略后可查看完整提示；类型较多时只在图例内部滚动，不无限撑高统计卡片。
- 新增或修改图表时先复用共享工厂；确需扩展样式时改共享实现并检查现有调用方，保留异步加载、空态、失败重试、尺寸变化与释放行为。默认不运行 UI 自动化，实际视觉由用户验收。

## 时间与时区

后台以北京时间 `Asia/Shanghai` 为统一显示和编辑时区，不能随浏览器/服务器系统设置变化。`assets.go` 在所有嵌入 HTML 的页面脚本之前注入 `runtime.js`，其中的 `window.AdminTime` 是时间入口；不另加同步依赖、CDN 或各页自己的格式化器。

- `AdminTime.dateTime(value, fallback)`：带时区的时刻 → `YYYY-MM-DD HH:mm:ss`；`date/time/short` 分别用于日期、钟点及图表短标签。空值、Go 零时间、无效或缺时区的时刻显示默认“—”或调用方空态，不伪造时刻。接口时间需保留 `Z`/明确偏移；不得 `replace('T',' ').slice(...)` 截掉时区，也不能用 `toLocaleString()` 的浏览器默认时区。
- `toInput/fromInput`：`datetime-local` 统一按北京时间回填、校验并转换为带时区的 ISO 值提交。输入框注明“北京时间”；通知定时发布/到期及轨迹起止时间未改动时回传原始值，保留秒、小数秒及原始时刻。服务器对兼容的无时区轨迹时间也明确按北京时间解析，不能使用 `time.Local`。
- 生日、筛选 `YYYY-MM-DD`、统计日期键是日历日期，原样传输；“今天”和未来生日校验取北京日期。AI 使用范围通过 `date/shiftDate` 计算，跨日不依赖浏览器时区。后台工作台/同行按日周月统计的边界显式采用北京时间。时长、倒计时和时刻比较使用时间差，不加时区偏移；分页游标原样透传。
- 工作台每日趋势及兼容的用户/上传趋势以同一自然日边界分桶：MySQL 通过 `repository/admin_daily_mysql.go` 将每个北京日的 `[start,end)` 作为 `time.Time` 参数合入一次批量 UNION ALL 聚合，日期标签与存储时区解耦，不直接对原始 DATETIME 做 DATE_FORMAT；不依赖 SQL 时区表或猜测连接的存储时区。Mongo/内存按传入窗口的时区归日，空日仍沿用接口补零，业务计数口径不变。
- 发现显示差8小时应检查数据、接口偏移和前端格式化，不修改数据库时间、连接全局时区或给时间戳直接加8小时来掩盖问题。

本轮统一覆盖用户列表/详情与设备权限、后台账号/登录菜单/审计、发布及更新日志、反馈纠错、埋点、路线组、同行列表/详情/位置/弹幕、投稿、AI 使用与价格、工作台、景点/候选和共用图表。纯日期校验、相对耗时、排序与发送当前时刻的 `toISOString()` 保留各自语义。

后续修改时间代码，先核对源字段的时区与时间戳单位，再静态检查 UTC `Z`、显式偏移、北京跨日、非北京时间浏览器、空/零/无效值、输入回填/保存及未修改精度；排查同类调用点，禁止只修报错的一列。验证仍遵守项目默认人工验收，不自动新增或运行业务/UI 测试。

## 改动导航

- **加一个管理后台 API**：在业务 handler 写实现 → 在 `routes.go` 的鉴权 api 组挂载 → 同步 `permissions.go` 的模块/读写/跨页面规则。需要操作者信息时用 `h.auth.SessionFromRequest(c)`；未知模块不能默认放行。
- **展示业务静态资源**：后台页面不要直接使用 `/api/v1/static/*`，应由 handler 改写为 `/admin/api/static/*`，通过 admin session 鉴权后读取 `staticRoot`。
- **加一个公开页面/资源**：把文件放进 `static/`，在 `routes.go` 用 `serveEmbedded(...)` 或走 `/admin/static/*filepath`。**不要新增第二个 `go:embed`**。
- **加一个侧边/顶部入口**：统一修改 `static/shell.js` 的导航配置；页面只需在自身脚本前加载 `shell.js`，不要再复制一份导航。
- **后台组件样式**：页面先加载内置 `vendor/tabler.min.css`，再加载 `style.css`；通用 Card / Button / Form / Table / Badge、移动端表格卡片化及图片点击全屏预览由 `static/ui.js` 统一增强，新增页面应加载 `vendor/tabler.min.js`、`shell.js`、`ui.js` 后再加载页面脚本，不要另写一套原生组件外观。地图图片或其他不应预览的图片可标记 `data-no-preview`。
- **改 cookie 策略**：只在 `auth.go` 改；保持 `HttpOnly=true`，跨站调用前提下才考虑 `SameSite=None + Secure`。
- **调整 session TTL**：改 `routes.go` 中 `NewSessionStore(12 * time.Hour)`，不要在 cookie 与 store 两边写不一致的过期时间。

## 提交前最小检查

- 构建：`go build ./...`
- 测试遵循根 AGENTS 的“默认验证方式”：默认不新增或运行，由用户手动验证；仅在用户明确要求时执行 `go test ./internal/admin ./internal/service` 或其指定范围，不自动扩大为全量测试。
- 路由变更：核对 `routes.go` 与 `static/*.js` 中前端 fetch 的 URL 是否一致。
- 静态资源新增：确认文件位于 `internal/admin/static/` 下（`go:embed static` 才能打包）。
- 页面/共享脚本/列表改动：逐项自查本文“页面性能约束”，对改动的 JS 执行 `node --check`；特别检查是否重新引入同步图表依赖、无版本动态资源、全页观察器扫描或重复逐行 I/O。不得把这些静态检查当作实际性能测量。
- 页面/Card/样式改动：逐项检查“卡片布局与边距约束”，同节点与子节点 card-body 的内边距必须都覆盖桌面/窄屏；任何 p-0 都要确认只作用于有意满宽的区域，不能消除标题、说明或工具栏留白。
- 接口契约变更：同步更新 `docs/api/feedback.md` 与 `docs/api/route-index.md`；`track_api.md` 仅保留轻量入口。

### 共享轨迹详情布局

顶部左侧为精简轨迹标签、右侧为稍宽的地图，统一16px间距；坐标系与地图标题同排。地图卡片顶部对齐，不随左侧内容拉伸，地图画布固定320px；991px以下顺排且画布固定240px。下方左侧资料卡集中基本信息、只读运动数据、路线说明，右侧248px资源栏仅展示一张1:1日间图和原始文件下载/大小/类型；991px以下按顺序单列，预览最大宽度240px，不放大为整屏大图。基本信息三列、标题/位置跨两列，767px以下两列、480px以下单列；各栏15px标题、12px次级文案，分隔线和留白保持一致。地图POI浮窗保留必要资料与确认操作，附近结果放入景点识别区。不得把轨迹文件指标提交为可编辑字段，也不删除未展示的其他预览资源。

标签默认仅三行：运动类型用原生下拉只展示当前值，图案、景点各展示一个当前名称，后接小“＋”。点击当前值或“＋”展开互斥小浮层，点外部或Escape关闭；长名称省略并可悬停查看。图案支持人工填写及清除，沿用shape_label单值和人工学习保护，需保存表单生效；景点支持选候选、搜索目录、确认新名称后新建并立即关联，以及原地图点选。两类手动AI按钮和诊断/学习展示移除，后台生成接口与自动任务保留。空值按后台快照显示“AI等待查询/AI正在查询/AI没有查到”，实际名称优先；状态读取失败保留“未设置/未关联”，不伪报无结果。精品等其他只读标签保留，不重复展示运动/图案/景点汇总；只读和已下架禁止修改。

原始文件元信息经现有raw资源接口的metadata=1异步读取，大小取缓存文件实际字节数，类型与下载扩展名一致；表单不等待文件缓存，失败可重试，下载入口保留，关闭弹窗取消请求。没有文件时只显示“缺失”，不编造大小或类型。

景点已保存候选与地图附近结果在浮层内仅展示名称标签，超过180px局部滚动；打开浮层才读取候选，不触发识别或供应商调用。候选沿用原确认接口立即关联，当前名称保留独立详情链接；忽略仍二次确认。人工名称搜索300ms防抖，目录view=picker最多20项，不扫描全目录排名或读取轨迹统计；同名项可通过悬停地区提示辨别，结果较多提示补全名称。搜索10秒超时可重试，输入变化/浮层关闭/详情关闭取消旧请求并忽略迟到结果。新建需轨迹与景点双操作权限、旧关联ID比较；只读/下架/繁忙锁不变。图案/景点均保持单值，“＋”用于设置或替换。

## 共用省市选择器

`static/region_picker.js` 的 `AdminRegionPicker.enhance(provinceSelect, citySelect, regions, options)` 合并已有省市控件，数据只消费 `/admin/api/cities` 的完整地区选项，不在组件内另发请求。轨迹、用户、同行、路线组、景点列表及景点新建表单复用，页面脚本前加载；后台原有go:embed与内容版本URL自然覆盖新资源。

展开后采用悬停级联：左列只列具体省份，不提供“全部省份”；左列始终保留、独立滚动，展开右列时位置和列宽保持不变。是否显示右箭头和城市列只依据目录中是否存在该省份的 city 子项，不硬编码直辖市名称。有子项时，鼠标悬停或触屏点击省份展开右列“全部”及所属城市，点击最终选项提交；无子项时（如北京市、上海市、重庆市）不显示箭头或空城市列，点击省份直接选中并收起，摘要只显示地区名。有子项但未指定城市的摘要如“陕西省 / 全部”，不使用“全省”。输入框右侧“×”清空省市筛选，回到“全部地区”；无筛选或原控件禁用时隐藏清除按钮，`allowAll:false` 的新建表单不提供清除。浏览过程不修改原控件，最终选择或清除后才同时更新隐藏原控件，并只向 citySelect 派发一次 change，避免中间查询覆盖城市结果。保留各页面的立即查询或点击搜索语义、原始地区 code 以及 city_code 优先规则。

原控件保留为查询/保存数据源，隐藏标签并由组件生成单个有名称的按钮；已存在实例再次enhance只更新数据。程序回填后可调用返回实例的sync，同步disabled状态和已选摘要；原控件选项重建由局部MutationObserver同步，不扫描整页。只读表单以原省份控件disabled为准，不能通过新按钮绕过。

输入框尾部图标互斥：可清除时用“×”替换下拉箭头，两者占用同一位置；清空后隐藏“×”并恢复下拉箭头。点击文字区域仍展开选择器，点击“×”仅清除筛选。未提供清除能力的表单继续显示下拉箭头。

弹层挂到body避让卡片/抽屉裁剪，限制于视窗、列表内滚动，复用Tabler语义色；窄屏字段换行。输入框使用表单底色和正文色，菜单普通项无填充、悬停浅灰、选中浅蓝底蓝字；`ui.js` 的通用按钮增强须跳过 `.admin-region-field` 与 `.admin-region-popup` 内的按钮，避免注入 `btn btn-primary` 导致蓝底深色字、居中文字与多余边框阴影。支持Enter/空格展开、上下/Home/End在当前列移动、左右键在省市列之间移动、Esc关闭，关闭后按操作来源恢复焦点；外部点击、页面滚动/缩放及离页关闭。
