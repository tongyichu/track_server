成长等级规则

成长等级使用累计 XP 计算。XP 来自有效轨迹，距离、时长、爬升、内容完整度和同行记录都会影响单次 XP。

1. 什么轨迹会计入等级

只有完成后的有效轨迹会计入 XP。进行中的轨迹、已删除或异常状态轨迹不会计入。

类型最短距离最短时长
跑步500 米3 分钟
徒步500 米5 分钟
爬山300 米5 分钟
骑行1000 米5 分钟
自驾3000 米5 分钟

不同类型的门槛不同，是为了避免短距离误触发，同时兼顾跑步、徒步、骑行、自驾等运动特性的差异。

2. 单次轨迹 XP 怎么算

单次 XP = 距离 XP + 时长 XP + 爬升 XP + 内容奖励 XP

距离 XP

距离是 XP 的重要来源，但不同类型采用不同权重，并且设置单次上限，避免某类运动因为距离天然更长而过度拉开等级。

类型每公里 XP单次距离 XP 上限
跑步15800
徒步18900
爬山12700
骑行61200
自驾1600

时长 XP

每 10 分钟获得 5 XP，单次最多 120 XP。时长用于鼓励持续完成，但不会无限叠加。

爬升 XP

类型规则
爬山每 100 米爬升 12 XP
骑行每 100 米爬升 6 XP
徒步每 100 米爬升 3 XP
跑步 / 自驾当前不额外计算爬升 XP

内容奖励 XP

  • 上传原始轨迹文件：+20 XP
  • 生成轨迹截图或无地图背景截图：+10 XP
  • 轨迹关联同行 session：+30 XP

4. 规则说明

  • 等级按累计 XP 计算，不直接按累计里程计算。
  • 自驾距离通常更长，因此每公里 XP 较低，并设置单次上限。
  • 跑步、徒步、爬山、骑行、自驾的 XP 会统一汇总到总等级。
  • 同一条轨迹更新后会重新参与统计，但勋章奖励会保持幂等，不会重复发放。
  • 会员权益不会直接提高通用 XP 倍率，避免形成付费等级优势。

如果轨迹数据存在明显异常，服务端可能不会将其计入有效轨迹或成就进度。

规则会根据产品策略和反作弊策略适度调整，以服务端当前计算结果为准。

Level Rules

Your level is calculated from total XP. XP comes from valid tracks, and each track may gain XP from distance, duration, elevation, content completeness, and companion sessions.

1. Tracks That Count

Only completed valid tracks count toward XP. Running tracks, deleted tracks, and abnormal tracks are not counted.

TypeMinimum DistanceMinimum Duration
Running500 m3 min
Hiking500 m5 min
Climbing300 m5 min
Cycling1000 m5 min
Driving3000 m5 min

Different thresholds reduce accidental records and reflect the natural differences between running, hiking, cycling, and driving.

2. Track XP Formula

Track XP = Distance XP + Duration XP + Elevation XP + Content Bonus XP

Distance XP

Distance is an important XP source. Each activity type has its own weight and per-track cap, so long-distance types do not create an unfair level advantage.

TypeXP per kmDistance XP Cap per Track
Running15800
Hiking18900
Climbing12700
Cycling61200
Driving1600

Duration XP

Every 10 minutes grants 5 XP, up to 120 XP per track. Duration rewards sustained activity without unlimited stacking.

Elevation XP

TypeRule
Climbing12 XP per 100 m elevation gain
Cycling6 XP per 100 m elevation gain
Hiking3 XP per 100 m elevation gain
Running / DrivingNo extra elevation XP for now

Content Bonus XP

  • Upload raw track file: +20 XP
  • Generate track screenshot or no-map screenshot: +10 XP
  • Track linked to a companion session: +30 XP

4. Notes

  • Levels are based on total XP, not total distance alone.
  • Driving usually has longer distance, so it has lower XP per km and a per-track cap.
  • Running, hiking, climbing, cycling, and driving XP all contribute to the total level.
  • Updating a completed track may update stats, while earned badges remain idempotent and are not granted repeatedly.
  • Membership benefits do not directly multiply general XP, to avoid pay-to-level advantages.

If track data is clearly abnormal, the server may exclude it from valid tracks or achievement progress.

Rules may be adjusted for product and anti-abuse reasons. The current server calculation is authoritative.
